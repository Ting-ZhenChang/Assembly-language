# RISC-V 數學運算程式

---

## 程式簡介

本程式使用 **RISC-V Assembly Language** 撰寫，透過使用者輸入兩個整數 **M** 與 **N**，計算以下四種數學運算：

1. 排列數 `P(M,N)`
2. 組合數 `C(M,N)`
3. 重複組合 `H(M,N)`
4. 次方運算 `M^N`

程式會先讀取 M 與 N 的值，再利用階乘函式計算所需結果，最後依序輸出各項運算結果。

---

## 數學公式

### 1. 排列數 P(M,N)

排列數公式：

\[
P(M,N)=\frac{M!}{(M-N)!}
\]

例如：

\[
P(5,2)=\frac{5!}{3!}=20
\]

---

### 2. 組合數 C(M,N)

組合數公式：

\[
C(M,N)=\frac{M!}{N!(M-N)!}
\]

例如：

\[
C(5,2)=10
\]

---

### 3. 重複組合 H(M,N)

重複組合公式：

\[
H(M,N)=\binom{M+N-1}{N}
\]

等價於：

\[
H(M,N)=\frac{(M+N-1)!}{N!(M-1)!}
\]

本程式採用下列等價公式計算：

\[
H(M,N)=\frac{M(M+N-1)!}{M!N!}
\]

---

### 4. 次方運算 M^N

\[
M^N=M\times M\times \cdots \times M
\]

共乘 N 次。

例如：

\[
2^5=32
\]

## 程式架構

### printID

輸出學號。

---

### changline

輸出換行字元。

---

### printM

顯示輸入提示：

```text
input number M =
```

---

### printN

顯示輸入提示：

```text
input number N =
```

---

### input

讀取使用者輸入的整數。

回傳值存放於：

```assembly
a0
```

---

### factoria

計算指定數值的階乘。

例如：

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

計算結果存放於 `a0`。

---

### printoutputP

計算並輸出排列數：

\[
P(M,N)=\frac{M!}{(M-N)!}
\]

---

### printoutputC

計算並輸出組合數：

\[
C(M,N)=\frac{M!}{N!(M-N)!}
\]

---

### printoutputH

計算並輸出重複組合：

\[
H(M,N)=\frac{M(M+N-1)!}{M!N!}
\]

---

### power

利用重複乘法計算：

\[
M^N
\]

---

### printpower

輸出次方運算結果。

## 錯誤處理機制

當輸入條件不符合規定時，程式輸出：

```text
No Output
```

---

### 排列數 P(M,N)

以下情況輸出 No Output：

```text
M <= 0
N < 0
M < N
M >= 13
```

---

### 組合數 C(M,N)

以下情況輸出 No Output：

```text
M <= 0
N < 0
M < N
M >= 13
```

---

### 重複組合 H(M,N)

以下情況輸出 No Output：

```text
M <= 0
N < 0
M >= 13
```

---

### 次方運算 M^N

以下情況輸出 No Output：

```text
M < 0
N < 0
M = 0 且 N = 0
```

## 執行範例

### 輸入

```text
input number M = 5
input number N = 2
```

### 輸出

```text
s1112463

P(M,N) = 20
C(M,N) = 10
H(M,N) = 15
M^N = 25
```

## 程式執行流程

1. 輸出學號。
2. 讀取 M 與 N。
3. 呼叫 `factoria` 計算：
   - M!
   - N!
   - (M−N)!
   - (M+N−1)!
4. 計算排列數 P(M,N)。
5. 計算組合數 C(M,N)。
6. 計算重複組合 H(M,N)。
7. 計算次方 M^N。
8. 檢查特殊條件與錯誤輸入。
9. 輸出結果。
10. 結束程式。

## 程式特色

- 採用模組化設計，將功能拆分為多個副程式。
- 使用共用的階乘函式，避免重複撰寫程式碼。
- 支援排列、組合、重複組合與次方運算。
- 具備錯誤輸入檢查機制。
- 有效利用暫存器保存中間計算結果。
- 適合作為 RISC-V 副程式呼叫與數學運算的練習範例。
